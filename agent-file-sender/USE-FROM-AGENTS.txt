ارسال فایل به تلگرام از Codex یا Antigravity

برای ارسال فایل‌هایی که کاربر درخواست کرده است، از فرمان زیر روی همین کامپیوتر استفاده کن:

& "$env:USERPROFILE\.n8n\scripts\agent-file-sender\Send-AgentFile.ps1" -FilePath "C:\path\to\file.pdf" -Caption "توضیح فایل"

آدرس واقعی فایل را جایگزین کن. APK، PDF، ZIP، عکس، ویدیو و سایر فایل‌ها به شکل Document فرستاده می‌شوند.
مقصد، چت شخصی صاحب سیستم با ربات هرمس است؛ به مقصد دیگری ارسال نکن.
توکن ربات در n8n می‌ماند و نباید درخواست، چاپ یا استخراج شود.

خروجی sent همراه messageId یعنی تلگرام دریافت فایل را تأیید کرده است.
خروجی already_sent یعنی همین فایل و توضیح قبلاً ارسال شده و دوباره ارسال نشده است.
در صورت DELIVERY_UNCERTAIN یا DELIVERY_UNCONFIRMED، قبل از هر ارسال مجدد رسید و اجرای قبلی را بررسی کن.
برای ارسال دوباره عمدی، فقط پس از درخواست کاربر از -Resend استفاده کن.

حد هر فایل: ۵۰٬۰۰۰٬۰۰۰ بایت. توضیح: حداکثر ۱۰۲۴ کاراکتر طبق محدودیت اعمال‌شده در فرمان.
مجوز محلی هرمس باید معتبر باشد؛ اگر بعد از Restart غیرفعال بود، دورش نزن.
در Codex این فرمان ممکن است به اجرای خارج از sandbox برای DPAPI نیاز داشته باشد.
ورک‌فلوی Agent File Sender - Codex and Antigravity به‌صورت دستی اجرا می‌شود و نیاز به فعال‌کردن Trigger ندارد.

راهنمای کامل کنار همین اسکریپت، در README.md قرار دارد.
